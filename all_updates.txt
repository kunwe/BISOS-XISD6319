1. REAL-TIME SALES REPORT UPDATES & VOIDING
--------------------------------------------------------------------------------
- Real-Time Sales Report Calculations: Recording a sale in recordSale()
  deducts stock, creates a new SaleItem with reference ID (TXN-xxxx), and
  instantly updates Total Sales, Transaction Count, Average Sale, and payment
  breakdowns (CASH, CARD, MOBILE) in real-time.
- Sale Voiding & Stock Restoration: Voiding a transaction in voidSale()
  automatically restores stock quantities and recalculates report totals.

2. MULTI-STORE DATABASE ISOLATION & STORE CREATION
--------------------------------------------------------------------------------
- Strict Per-Store Disk Database: Each store branch (Soweto Supermarket,
  Sandton Branch, Pretoria Branch) maintains its own isolated database state
  on disk (store_products_{id}, store_sales_{id}) and online for products,
  stock levels, low-stock alerts, sales, and reports.
- Add New Store Branch in Settings: Dedicated "+ New Branch" button in
  Settings ➔ Store Information opens an Add Store dialog (Store Name,
  Address, Company Tel), creates a new store branch, initializes an isolated
  database, and sets it as active.
- Multi-Store Registration: "Store Managing Details" section on Register screen:
  * Join Existing Store (Dropdown selection of saved database stores).
  * Create New Store (Editable text fields for Store Name, Address, Company Tel).
- Active Store Switcher: Settings header displays active store with an
  interactive dropdown switcher to change managed branches.

3. GOOGLE SIGN-IN & MANDATORY REGISTRATION REDIRECTION
--------------------------------------------------------------------------------
- Registration Verification: Tapping "Sign in with Google" or "Sign up with Google"
  checks if the Google email is registered.
- Automatic Redirection: If un-registered, alerts user ("Account is not
  registered yet. Redirecting to Register...") and automatically redirects
  them to RegisterScreen.kt to complete store setup.

4. FIREBASE AUTHENTICATION INTEGRATION
--------------------------------------------------------------------------------
- Cloud Identity Management: Configured Firebase BoM (33.9.0), Firebase Auth
  (firebase-auth-ktx), and Google Services plugin (com.google.gms.google-services:4.4.2).
- FirebaseAuthManager: Handles signInWithEmailAndPassword, createUserWithEmailAndPassword,
  and user session management across Firebase, local storage, and MySQL.

5. PROFILE PICTURE MANAGEMENT IN SETTINGS
--------------------------------------------------------------------------------
- Interactive Avatar: Tapping user avatar on Settings screen opens Profile Photo dialog.
- Photo Options: Camera/photo upload, AI avatar picker, or photo removal with
  SharedPreferences (profile_prefs) persistence across restarts.

6. FULL-APP MULTI-LANGUAGE LOCALIZATION
--------------------------------------------------------------------------------
- 4 Languages Supported: Complete string resources and translations for:
  * English (Default)
  * Afrikaans (res/values-af)
  * isiZulu (res/values-zu)
  * Sesotho (res/values-st)
- Instant Locale Refresh: Changing language in Settings immediately updates app
  locale and translates all text elements across all screens.

7. STOCK & INVENTORY MANAGEMENT & AI IMAGE GENERATOR
--------------------------------------------------------------------------------
- Clickable Stock Cards: Tapping any card opens "View & Edit Product" modal
  dialog to modify Name, Price, Stock Quantity, Threshold, and Barcode.
- AI Stock Image Generator (Pollinations.ai): Generates real-time product images
  based on product names with smart measurement parsing (kg, L, ml, mg, g, pack).
- Image Control Options:
  * ✨ Regenerate AI Image
  * 📷 Replace Photo (Camera capture/upload)
  * 🗑️ Remove Image (Reverts to clean ic_store icon)
- Barcode Scanner & Search: Search bar filtering inventory by name or barcode.

8. PHP BACKEND API ENDPOINTS REFERENCE (http://localhost/bisos-php/api)
================================================================================
GET  /ping                     - Health check ping
POST /auth/login               - Login & return JWT/token + user object
POST /auth/register            - Register user account (Online & Sync)
GET  /stocks?store_id={id}     - Fetch products & stock levels for store
POST /products                - Add new product to store
POST /products/update          - Update product name, price, stock, threshold
POST /products/delete          - Delete product from store
GET  /alerts?store_id={id}     - Fetch low stock alerts (< 50 items)
POST /sales                    - Record new sale & deduct stock quantity
POST /sales/void               - Void sale & restore stock quantity
GET  /sales/report?store_id={id}- Fetch sales report & payment method totals

9. MYSQL DATABASE TABLES (bisos_db)
================================================================================
- Store             (store_id, name, address, phone, manager_name)
- User              (user_id, store_id, role_id, username, email, password_hash)
- Product           (product_id, store_id, name, category, barcode, cost_price, selling_price, reorder_level)
- Stock             (stock_id, product_id, quantity, minimum_level, maximum_level)
- LowStockAlert     (alert_id, product_id, current_quantity, reorder_level, status)
- SalesTransaction  (transaction_id, store_id, transaction_ref, payment_method, total_amount, status)
- SalesItem         (sales_item_id, transaction_id, product_id, quantity, unit_price, total_price)

10. HOW TO LINK APP AND PHP WEBSITE
================================================================================
1. Start WAMP/XAMPP Apache and MySQL services on your computer.
2. Import database/schema.sql and database/seed.sql into MySQL.
3. Place bisos-php files in C:\wamp64\www\bisos-php\
4. Access website at: http://localhost/bisos-php
5. The Android app connects to http://localhost/bisos-php/api (or 10.0.2.2 for emulator / ngrok URL for device).
